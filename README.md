# SQL Practice: Основы реляционных баз данных 🗄️

Этот репозиторий содержит мои первые практические работы по изучению SQL и интеграции баз данных в Python-приложения. Здесь я отрабатывал фундаментальные навыки управления данными.

## 🎯 Что было изучено и реализовано:
- **Проектирование БД:** Создание таблиц с использованием правильных типов данных и ограничений (`PRIMARY KEY`, `NOT NULL`, `UNIQUE`).
- **CRUD-операции:** 
  - `CREATE`: Создание структуры таблиц.
  - `READ`: Получение данных с использованием фильтрации (`WHERE`) и сортировки.
  - `UPDATE`: Обновление существующих записей в базе.
  - `DELETE`: Безопасное удаление данных и таблиц (`DROP TABLE`).
- **Синтаксис условий:** Составление запросов для поиска конкретной информации по заданным параметрам.
